# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| Latest release on [GitHub Releases](https://github.com/e-vicius/steppy-desktop/releases) | Yes |
| Older tags | Best effort |

## Reporting a vulnerability

**Please do not open a public GitHub issue for security problems.**

1. Use [GitHub private vulnerability reporting](https://github.com/e-vicius/steppy-desktop/security/advisories/new), or
2. Email **hello@steppy.app** with steps to reproduce, impact, and affected versions.

We aim to acknowledge reports within a few business days and will coordinate disclosure once a fix is ready.

## Scope

- Steppy desktop app (this repository)
- Official installers published from this repository’s release workflow

The marketing site ([steppy-landing](https://github.com/e-vicius/steppy-landing)) is in scope for site-only issues; app vulnerabilities should be reported against this repo.

## Out of scope

- Misconfiguration of third-party AI providers or API keys you supply
- Social engineering
- Issues in unsupported or modified builds
