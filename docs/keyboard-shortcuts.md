# Keyboard shortcuts

## Main window

| Shortcut | Action |
| --- | --- |
| **⌘R** / **Ctrl+R** | New recording (source picker) — not while recording |
| **⌘E** / **Ctrl+E** | Export — when a guide is open |
| **⌘,** / **Ctrl+,** | Settings |
| **Escape** | Clear step selection (when not typing in a field) |

## While recording (global)

These work even when Walkmark is in the background. Shown in the HUD as **⇧⌥** on Mac (Shift + Alt).

| Shortcut | Action |
| --- | --- |
| **Shift + Alt + S** | Finish recording |
| **Shift + Alt + M** | Capture this moment (manual step) |
| **Shift + Alt + P** | Pause / resume |

## Step rail selection

| Input | Action |
| --- | --- |
| Click | Select step |
| **⌘** / **Ctrl + click** | Toggle step in selection |
| **Shift + click** | Select range |

Use multi-select for **Merge**, **Exclude**, or **Delete** from the floating bar.

## Image editor

Open from a step screenshot to add blur, cover, or highlight regions.

| Shortcut | Tool |
| --- | --- |
| **V** | Select |
| **B** | Blur |
| **R** | Cover (solid redact) |
| **H** | Highlight |
| **⌘Z** / **Ctrl+Z** | Undo last annotation |
| **Delete** / **Backspace** | Remove selected region |
| **Escape** | Close editor |

## Tips

- Shortcuts follow the platform convention: **⌘** on macOS, **Ctrl** on Windows and Linux.
- Global recording shortcuts require the app to have registered them at record start; if they fail, use the HUD buttons or **Stop** in the main window.
